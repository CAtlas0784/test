### Common Execution Errors & Resolutions
- **Error: `UnityPlayer.dll not found next to StarRail.exe`**:

  - Fix: Copy `StarRail.exe` (or rename original `StarRail.exe` to `StarRail_orig.exe` and copy this one + `hsr-frontend.exe`) into the Star Rail `Game` folder.
- **Error: Frontend Disconnected / Dump Failed**:
